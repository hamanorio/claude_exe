# 模擬診察の台本(文字起こしの精度評価・マイクの録り比べ用)

実在の患者さんの情報を含まない、架空の診察会話です。台本の文章がそのまま
「正しい文字起こし」になるので、正解ファイルを聞き直して作る手間がかかりません。

| ファイル | 場面 | 長さの目安 |
|---|---|---|
| 01_甲状腺.txt | バセドウ病の初診(検査結果の説明、抗甲状腺薬の副作用) | 約2分 |
| 02_循環器.txt | 発作性心房細動の疑い(ホルター心電図、抗凝固薬) | 約2分 |
| 03_呼吸器.txt | 気管支喘息の再増悪(聴診所見、吸入薬) | 約2分 |
| 04_消化器.txt | 急性胆嚢炎(腹部の診察、入院の説明) | 約2分 |
| 05_神経.txt | 一過性脳虚血発作(神経診察、当日の検査) | 約2分 |

これまでに誤認識が多かった語(動悸、著明、遊離T4、暑がり、不順、寛解など)と、
①-2の音照合で誤った候補が出やすかった普通の言葉(階段、判断、効果、中心、段階、
全員、乾燥、対応、服用など)を、わざと含めてあります。

## マイクの録り比べの手順

1. 医師役と患者役の2人で、台本を読み上げます。「医師:」「患者:」の部分は読みません。
   棒読みにならないよう、普段の診察の速さと声の大きさで読んでください。
2. 同じ読み上げを、今のマイクと外付けマイクで**同時に**録音します。
3. 録音と台本を1つのフォルダにまとめ、次のような名前にします
   (「__」の前を台本の名前と同じにすると、台本が両方の正解として使われます)。

       asr_mic/
           01_甲状腺.txt            ← scripts からコピー
           01_甲状腺__今.m4a
           01_甲状腺__外付け.m4a

   台本のコピーは次のコマンドでできます。

       mkdir -p asr_mic && cp scripts/0*.txt asr_mic/

4. 評価します。

       python3 eval_asr.py --dir asr_mic --engines mlx:large-v3-turbo --sound-match --out asr_mic.csv

## 注意

- 読み間違えたり言い直したりした箇所は、台本の txt もその通りに直してください
  (台本と実際の発話が違うと、その分が文字起こしの誤りとして数えられます)。
- 読み上げは自然な会話より整った話し方になるので、実際の診察より誤りは少なめに出ます。
  マイクやエンジンの「比較」には十分使えますが、実際の精度の見積もりには使えません。
